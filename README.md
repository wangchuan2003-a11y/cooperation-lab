# Cooperation Lab · 合作博弈实验

六种固定策略在重复囚徒困境中相遇。调整轮次、执行噪声和种子，查看真实计算的平均得分、合作率、对局矩阵、动作轨迹与累计得分曲线。没有 AI 模型、后端、账户或 API 密钥。

## 运行

需要 Node.js 22。

```sh
npm ci
npm run dev      # http://127.0.0.1:5199，严格端口
npm test
npm run build
npm run preview  # http://127.0.0.1:4199，严格端口
npx playwright test --list
```

真实浏览器回归在 GitHub Actions 安装 Chromium 后执行 `npm run test:e2e`。本地无需安装或启动独立浏览器即可运行模型测试与生产构建。

## 模型定义

每轮双方同时决定意图。执行噪声以设定概率独立翻转每方的实际动作；收益按**实际动作**计算，策略下一轮观察的也是实际历史，不知道对方原意。噪声范围 0–20%，轮次为 20–300。噪声“误会情景”只是界面情景名，本模型没有另外的观察误差或私有信念。

| 左 / 右实际动作 | 左 / 右收益 |
|---|---|
| C / C | 3 / 3 |
| D / C | 5 / 0 |
| C / D | 0 / 5 |
| D / D | 1 / 1 |

固定 `T = 5 > R = 3 > P = 1 > S = 0`，且 `2R > T + S`。C 表示合作，D 表示不合作；“得分”只是该收益表中的数值。

| 策略 | 确切实现 |
|---|---|
| Always Cooperate / ALL C | 每轮意图均为 C。 |
| Always Defect / ALL D | 每轮意图均为 D。 |
| Tit for Tat / TFT | 首轮 C，之后复制对方上一轮实际动作。 |
| Generous Tit for Tat / GTFT | 首轮 C；对方上一轮 C 则 C，若 D 则以 10% 概率宽恕为 C，否则 D。10% 是本实验固定参数，不宣称普遍最优。 |
| Grim Trigger / GRIM | 首轮 C；对方出现任何一次实际 D 后，所有后续轮次意图均为 D，不恢复。 |
| Win Stay Lose Shift / WSLS | 首轮 C；上一轮实际收益为 3 或 5，重复自己的上一轮实际动作；为 0 或 1，则切换自己的上一轮实际动作。 |

规则决定意图后，噪声仍可翻转动作，包括已经触发的 GRIM 或 ALL D。任何“永久不合作”的描述都指意图，不是保证噪声后的实际动作。

### 比较与复现

六策略全部无序配对，**包含自我对局，共 21 局**。每局使用相同轮数，无折现、无退出、无跨局记忆。对角线取自我对局双方的平均每轮得分和合作率；非对角线每格是行策略作为对应一方时的结果。因此每种策略的排名分数是矩阵一行的六个格子等权平均，不会把自我对局重复加权。界面“策略平均合作率”再对六个策略的合作率等权平均。

伪随机数采用本地 Mulberry32 流。每个无序策略对从总种子派生自己的种子；每方的策略随机流和执行噪声流分离，宽恕策略多抽一次随机数不会改变执行噪声序列。设置相同就可复现。反向选择一场对局只是交换已经计算的双方数据，不重新抽样。

分享链接保存轮次、执行噪声、32 位种子以及左右策略。逐轮查看的滑块位置是临时视图，不改变实验。CSV 导出当前所选对局的所有轮次，含双方意图、实际动作、执行翻转标记、当轮和累计得分；使用 UTF-8 BOM 方便表格软件读取。

## 为什么不把排名当作道德结论

这是有限轮次实验，但这六种固定策略**没有利用已知终局来倒推**，不是子博弈精炼均衡求解器。它不含人类动机、学习、沟通、声誉网络、退出、不同信息结构或现实合作关系的成本。

单个种子的排序只是此策略集合、轮数、收益表和误差过程下的一个样本。换对手组成、参数或种子可能改变结果。高得分不等于善意、信任或道德价值；这些算法也不提供真人行为建议。应把图表当作提出和检查问题的工具，而非“找到了合作的唯一答案”。

## 检查

模型回归覆盖四格收益、六策略的精确规则、全合作/全不合作/TFT 对 ALL D 的闭式结果、噪声与实际收益一致性、种子复现与取值范围、21 局汇总、自局双席平均、矩阵反向读取、非法分享参数和 CSV 数据。测试中统计检查只是对实现的回归，不是随机性的理论证明。

桌面与手机浏览器回归覆盖已知无噪声结果、矩阵选择对局、噪声实际动作、种子重跑、完整分享复现、坏链接保留当前状态和 CSV 文件内容；同时检查浏览器错误和页面水平溢出。动作轨迹提供轮次滑块和文本明细作为键盘/读屏替代，矩阵与长轨迹只在自身容器内滚动。
